# tilda-media

Публичные медиафайлы (видео) для сайтов на Тильде. Тильда не принимает загрузку видео, поэтому ролики лежат здесь и отдаются через CDN jsDelivr.

Здесь только файлы, которые и так видны на сайтах. Ничего приватного сюда не класть.

## vitamishki.uz
- `vitamishki/hero-loop-d.mp4` — живой фон первого экрана для ПК (Kling 3.0 Pro, 8 с, 1920×1080, без звука, бесшовный цикл)
- `vitamishki/hero-loop-m.mp4` — то же для телефона (5 с, 720×1280)

Ссылки для сайта (версия закреплена тегом, кэш CDN):
- https://cdn.jsdelivr.net/gh/Jacob-Freeman/tilda-media@v1/vitamishki/hero-loop-d.mp4
- https://cdn.jsdelivr.net/gh/Jacob-Freeman/tilda-media@v1/vitamishki/hero-loop-m.mp4

Новую версию файла выкладывать с новым тегом (v2, v3…) и менять тег в коде сайта.
